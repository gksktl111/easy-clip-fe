## 2026-09-08 이어서 수행한 수정·검증

- 저장 실패 초안이 남은 동안 새 붙여넣기로 기존 텍스트·파일을 덮어쓰지 않도록 수정했다. 사용자가 다시 저장하거나 버리기를 선택한다. 기존 4개 언어 저장 오류 E2E도 초안을 명시적으로 버린 뒤 다음 입력을 검증하도록 변경했다.
- 텍스트 초안의 덮어쓰기 방지·화면 이동 후 보존, 이미지 파일명과 실제 업로드 바이트의 재시도 보존, `upgradeCanResolve` 참/거짓에 따른 안내를 E2E로 검증했다.
- 결제 confirm 동시 호출·화면 재진입, 네트워크 응답 유실 후 재호출·새로고침, 제출 이력 저장 실패 시 미전송을 단위 테스트로 검증했다. 실제 청구는 수행하지 않았다.
- 화면 복귀 중 늦은 Pro 응답 차단과 별개로, 화면을 연 채 종료 시각에 도달했을 때 폴더를 다시 확인하고 잠근다는 E2E를 추가했다.
- 클립·휴지통 모두 서버 커서를 그대로 사용하고 다음 페이지 404 후 이전 목록을 버려 첫 페이지부터 다시 읽는 E2E가 통과했다. 휴지통 모킹에서는 Next.js `_rsc` 미리 가져오기 요청을 제외한다.

## 실제 배포 환경: 외부 차단

2026-09-08 README에 명시된 `https://api.easy-clip.app`를 읽기 전용으로 확인했다.

- `/docs-json`, `/folders`, `/subscriptions/me` 모두 HTTP 403.
- 공개 문서 응답은 `Server: cloudflare`, `Content-Type: text/plain; charset=UTF-8`, 본문 `error code: 1010`이었다. 이를 애플리케이션의 `PROJECT_LOCKED` 응답이나 정책 배포 증거로 판정하지 않는다.
- 현재 `.env.local`의 API 설정은 로컬 주소다. 실제 서비스의 검증 가능한 인증 세션은 확보하지 못했다.
- 실제 청구, 실사용 데이터 생성·수정·삭제, 서비스 배포는 수행하지 않았다.

실서비스 검증에 필요한 것은 Cloudflare에서 허용된 실행 환경과 검증용 계정이다. 그 환경에서 `GET /folders`의 `isLocked`, 실제 정책 오류 응답, 이름 단독 수정 API, 해당 마이그레이션 배포를 확인해야 한다. 이 외의 위 로컬 검증 항목은 남아 있지 않다.
