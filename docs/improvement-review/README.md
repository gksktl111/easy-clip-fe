# 19개 항목 검토와 개선 작업 제안

검토일: 2026-09-08 · 기준: 로컬 `dev`, `e8b47e2` · 상태: 검토·제안 문서, 구현 지시서 초안

사용자가 제시한 순서대로 1~19번을 부여했다. 아래 상태는 소스와 기존 테스트를 기준으로 하며 배포 환경의 재현 결과가 아니다. 정책 제안, API 추가안과 성능 목표는 아직 확정된 서비스 계약이 아니다. 초기 문서 작성에서는 제품 코드를 변경하지 않았다. 후속 요청으로 해결된 항목을 제외한 15개 이슈를 등록했으며 [등록 결과와 제외 근거](issue-registration.md)에 기록했다.

## 항목별 판단

P1은 핵심 기능·목록 신뢰성 우선, P2는 다음 개선 묶음, P3는 단계적 구조 개선을 뜻한다. 배포 재현 결과에 따라 우선순위를 조정한다.

| 번호 | 항목 | 현재 판단 | 우선순위·다음 행동 |
| --- | --- | --- | --- |
| 1 | 최근 항목 즐겨찾기 | 코드상 이벤트 연결 누락 확인 | P1, 연결과 회귀 테스트 |
| 2 | 최하단 폴더 한 칸 위 이동 | 현 로직은 이동 가능, UI·API 재현 필요 | P2, 메뉴와 드래그 분리 검증 |
| 3 | Pro 버튼 색상 | 전용 토큰·버튼 구현 존재, 시각 재검증 필요 | P2, 테마·상태별 검증 |
| 4 | 비로그인 요금제 리다이렉트 | 현재 public 허용, 과거 보고와 차이 | P2, 배포 버전·쿠키 확인 |
| 5 | mutation 뒤 조회 클립 유실 | 원인 미확정, 재조회 충돌 가능성 | P1, 14·15와 공동 재현 |

| 7 | 폴더 태그 관리·클립 배치 | 구현됨, 폴더 화면에서 편집 가능 | 유지 검증, 다른 목록의 편집 범위 결정 |

## 상위 작업과 진행 순서

| 상위 작업 | 하위 항목 | 선행 조건 | 완료 기준 |

| URL과 탐색 상태 | 11·12, 13 회귀 포함 | URL 정책 확정 | 직접 진입·새로고침·뒤로가기 조건 일치 |
| 구독 권한과 폴더 제한 | 8·9 | 서버 제한·잠금 계약 합의 | 해지 예약·만료·재구독 상태별 권한 일치 |
| 폴더 정렬 | 2·17 | 메뉴/드래그/API 원인 분리 | 인접 이동·롤백·키보드 이동 통과 |
| 공개 페이지와 초기 진입 | 3·4·6·10 | 배포 버전·성능 기준선 확인 | 공개 접근·404·테마·느린 설정 응답 검증 |
| 구현 유지와 구조 개선 | 7·16·18·19 | 위 동작 안정화 | 기존 기능 회귀 없이 점진 적용 |

먼저 1번의 연결 누락을 수정하고 5·14·15의 재현을 확보한다. 동시에 6번은 실제 이동 경로와 서버 지연을 측정한다. 다음으로 8·9와 11·12의 정책을 합의한 뒤 구현하며, 2·17과 공개 페이지 검증을 이어간다. 이미 구현된 7·13은 중복 개발 대신 유지 검증 대상으로 관리한다.

## 검증 범위

이번 문서 작성 중 폴더 정렬, Infinite Query 옵션, 태그 캐시 관련 기존 단위 테스트 3개 파일·8개 테스트를 실행해 모두 통과했다. 이는 배포 버그 해결 증명이 아니다. 배포 브라우저 재현, 네트워크 추적, 실제 백엔드 권한·커서 계약 검증은 미수행이며 각 문서에 필요한 시나리오를 명시했다. 문서만 추가하므로 제품 빌드·전체 E2E는 다시 실행하지 않았다.

프레임워크 참고 기준은 저장소의 Next.js 16.1.1, React 19.2.3, TanStack Query 5 계열, next-intl 4 계열이다. 공식 최신 문서의 설명을 참고하되 구현 시 설치 버전과 다시 대조한다.
