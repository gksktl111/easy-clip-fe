# 남은 작업 · BE 에이전트 전달용

2026-09-11 확인 기준. FE는 별도 담당한다. **이번 문서는 전달할 작업 정리이며 BE 코드·설정은 수정하지 않았다.**
기존 사용자 변경을 보존하고 각 저장소 지침을 따른다. 커밋·push·배포 범위는 별도 지시에 따른다.

## P1 · 먼저 진행할 작업

| 항목 | BE에 요청할 구현 | 완료 기준·FE 협의 |
| --- | --- | --- |
| 가격 계약 F1/O5 | 공개 금액·통화·결제 주기 계약을 제공하고 최초 결제·자동갱신의 가격 기준을 통일 | 현재 FE 표시 3,900원, BE 기본값 4,900원. 운영 금액은 별도 확인. 실제 청구와 공개 값이 일치하며 필드·오류·가격 변경 처리 방식을 FE에 전달 |
| CSRF S2 | 쿠키 인증 상태 변경 요청의 출처 검증과 CSRF 방어 | 불허 출처 요청 거부. Bearer 앱 요청·OAuth 콜백을 구분. FE에 필요한 헤더·토큰 계약 전달 |
| OAuth state S3 | 로그인 시작 브라우저와 state를 연결하고 일회성 처리 | 정상 로그인 성공, 다른 브라우저·재사용·만료 요청 거부. 계정 연결 시 시작 사용자와 콜백 세션 일치 |
| 인증 로그 S4 | 예외 로그의 originalUrl에서 인증 쿼리 제거, 공통 로그 정제 적용 | 가짜 code/state를 포함한 실패 요청의 최종 로그에 원문 없음 |
| 이미지 업로드 S5 | multipart 수신 단계 크기·개수·파트 제한, 실제 파일 형식 검사와 요청 제한 | 초과 파일 조기 거부·MIME 위장 거부. 프록시 제한과 정합성 확인 |
| 최초 결제 S6 | 결제 시도를 서버에 먼저 기록하고 멱등 처리·결과 조회/대사 구현 | 동시 요청·응답 유실·DB 실패에서 청구 1회와 결과 복구. 테스트 게이트웨이 사용, 실과금으로 검증하지 않음 |

상세 근거와 기존 코드 위치: [01 기능](01-functionality.md), [03 보안](03-security.md), [05 최적화](05-code-optimization.md).
변경된 요청·응답·오류 계약은 FE 구현 전에 공유한다. 마이그레이션이 필요하면 기존 데이터 영향과 적용 순서를 명시한다.

## 운영자 결정 필요 · 에이전트가 임의 확정하지 않음

- 실제 판매 가격, 환불·자동갱신 정책.
- 운영자·개인정보 담당자, 보유·파기 기간, 실제 외부 처리 업체·국가와 연락처.
- 공개 CDN 보관 정책 유지 여부. 비공개 자료 보관을 목표로 바꾸면 private 객체·인증 URL 전환을 별도 설계.

이 정보가 확정되면 [FE 작업](07-remaining-fe.md)의 정책 페이지·가격 표시와 연결한다.
