## FE 적용 결과 · 2026-09-11

- **A1~A6 적용:** 배경 광원·반복 배지·큰 그림자·카드 이동·중첩 박스를 정리하고 사용 흐름을 저장→검색→복사 예시로 바꿨습니다. 출처 미확인 후기는 01/02 작업에서 제거했습니다. 실제 기기 프레임·상태색·태그는 유지했습니다.
- **D1 적용:** 공통 모달에 이름, 초기 포커스, Tab 순환, Esc, 배경 비활성화, 닫기 후 포커스 복귀를 추가했습니다. 중첩 모달과 알림 닫기를 유지하고, 모바일 설정을 닫으면 열린 사이드바로 돌아옵니다. 모달 안 붙여넣기는 뒤쪽 클립 생성으로 전달하지 않습니다.
- **D2/D3 적용:** 네 언어 결제 안내는 01에서 반영했습니다. 이번에는 결제 확인 중·완료·실패·결과 불명확의 제목과 아이콘을 구분하고 모션 최소화 설정을 적용했습니다. 랜딩 제목은 단어 단위 줄바꿈과 균형 배치를 사용합니다. 모바일 사이드바 버튼 이름도 번역했습니다.
- **D4 부분 적용:** 긴 본문·제목·전체 태그·이미지를 읽고 복사하는 미리보기를 추가했습니다. 현재 접근 가능한 목록에서만 열리며 폴더 잠금 시 닫힙니다. 별도 촘촘한 목록 모드는 실제 사용량·선호를 확인한 뒤 결정할 후속 항목입니다.

검증: 4개 언어 × 2개 테마 × 390/768/1440px에서 랜딩·요금·결제·설정의 가로 넘침과 키보드 조작을 확인했습니다. 미리보기 복사·모달 종류별 Esc·결제 상태 테스트를 추가했습니다. overflow 수정 후 전체 CI도 lint·typecheck·Webpack production build·단위 테스트 123개·E2E 114개와 Storybook build를 통과했습니다. 자동 스캔은 **234개 파일·14종·99개 기록**으로 줄었지만, 이를 결함 개수나 접근성 인증으로 해석하지 않습니다. 전체 대비 수치·모든 보조기술은 미검증입니다.

### 후속 개선 · 새로고침 시 권한 대기 화면

새로고침할 때 표시하던 큰 잠금 아이콘·권한 확인 제목을 목록 스켈레톤으로 바꿨습니다. 폴더·최근 항목·즐겨찾기는 기존 카드 형태, 휴지통은 기존 행 형태를 재사용합니다. 화면 읽기 도구에는 권한 확인 중이라는 이름과 busy 상태를 제공합니다.

권한 확인이 끝나기 전에는 실제 자료를 조회·표시하지 않습니다. 오류·잠금 안내와 재시도, 계정 전환·구독 변경·만료 시 차단 정책은 유지합니다. 권한 결과를 브라우저 저장소에 보존하거나 재확인을 생략하지 않습니다.

최초 진입·새로고침 4개 경로와 오류→재시도→잠금 안내를 검증하는 E2E 5개를 추가했습니다. 개별 E2E 5개가 통과했고 최종 전체 CI도 lint·typecheck·Webpack production build·단위 테스트 123개·E2E 119개·Storybook build를 통과했습니다. [클립 대기 화면](assets/access-loading-clips-mobile.png) · [휴지통 대기 화면](assets/access-loading-trash-mobile.png).

## 제거 대상으로 보지 않은 항목

- **기기 프레임·실제 제품 캡처·큰 Hero 제목·상단 단일 CTA:** [기존 랜딩 계획](../landing-design-improvement-plan.md)에 명시된 의도입니다. 프레임의 금속 그라데이션까지 배경 장식과 함께 일괄 삭제하지 않습니다. Hero 제목의 한 구절 강조도 그라데이션 글자가 아닙니다.
- **단계 번호와 클립 카드 그리드:** 실제 작업 순서와 자료 목록을 표현합니다. 번호·그리드가 있다는 이유만으로 결함으로 분류하지 않습니다.
- **상태색·아바타·스위치·태그·로딩 표시:** 의미가 있는 색과 형태입니다. `FilterBar.tsx:82`의 맥동도 실제 저장 중 상태이며 가짜 “실시간” 표시가 아닙니다. 비활성 상태의 빨강 사용은 오류처럼 보이지 않도록 중립색으로 바꾸는 정도를 검토합니다.
- **SVG와 글꼴:** 탐지된 SVG는 로그인 로딩 원이고, 글꼴은 한글 fallback을 포함한 시스템 스택입니다. AI가 그린 로고나 기본 Inter 조합으로 판단하지 않았습니다.
- **모서리 테두리·작은 제목:** 탐지된 카드 대부분은 같은 요소에 border와 radius를 적용합니다. 깨진 모서리라고 단정하지 않습니다. 모달 제목 크기만으로 위계 실패라고 판단하지도 않았습니다.

`Button.tsx:43`의 하드코딩된 빨강은 공통 danger 토큰으로 정리할 후보지만, 위험 동작을 표시하는 의미 자체는 유지합니다. 아바타·상태 배지·404 숫자와 저작권 기호도 정상 요소로 분류했습니다.

## D1 · P1 — 설정 모달 키보드 조작 실패 [재현]

모달을 연 뒤 Tab을 누르면 뒤쪽 필터·검색·클립으로 이동합니다. Esc도 닫기를 수행하지 않습니다. 설정 모달에는 dialog 의미와 초기 포커스 설정도 없습니다.

**개선:** 공통 Modal이 초기 포커스, 모달 내부 Tab 순환, 닫을 때 원래 버튼으로 복귀, Esc, 배경 비활성화를 담당하도록 합니다. 제목 연결도 공통화합니다. 저장 중 닫기 정책은 각 화면에서 정합니다.

**완료 기준:** 설정·이름 변경·삭제 확인·태그·구독 해지 모달을 키보드만으로 열고 조작하고 닫을 수 있음.

근거: [공통 Modal](../../src/shared/ui/overlay/Modal.tsx), [설정 모달](../../src/features/settings/ui/SettingsModal.tsx).

## D2 · P1/P2 — 결제 화면의 정보 우선순위와 언어 혼합 [재현·제안]

영어 설정에서도 제목·버튼은 한국어로 남습니다. “서버에서 구독 상태를 Pro로 갱신”은 사용자가 판단할 정보가 아닙니다. 반면 실제 가격·자동갱신·해지 후 이용 기간은 결제 결정에 중요합니다. 예정인 AI 기능도 현재 혜택과 같은 체크 표시를 사용합니다.

**개선:** 서버의 확정 가격 → 결제 주기·자동갱신 → 현재 이용할 기능 → 결제 버튼 순으로 정리합니다. 기술 설명은 이용 시작 시점 설명으로 바꾸고, 예정 기능은 별도 표기합니다. 문구 전체를 번역합니다.

**완료 기준:** 네 언어에서 가격·청구 주기·현재 제공 기능을 오해하지 않음. [모바일 영어 화면](assets/billing-mobile-en.png).

근거: [결제 화면](../../src/features/subscription/ui/BillingPage.tsx), [안내](../../src/features/subscription/ui/BillingHeroSection.tsx), [혜택](../../src/features/subscription/ui/BillingUnlockedFeatureList.tsx).

## D3 · P2 — 랜딩 제목 줄바꿈과 반복 콘텐츠 [재현·제안]

1440px 화면에서 “저장하고, 찾고, 다시 쓰는 간단한 흐름”의 마지막 “름”만 다음 줄로 떨어집니다. 기능 소개와 사용 흐름은 비슷한 내용을 반복하고, 후기에는 동일 인물이 반복됩니다. 후기 배너는 계속 움직이지만 일시정지와 reduced-motion 처리가 없습니다.

**개선:** 제목에 한국어 단어 단위 줄바꿈을 적용하고 폭·글자 크기를 함께 조정합니다. 사용 흐름은 실제 제품 예시로, 기능 소개는 차별점으로 역할을 구분합니다. 출처를 확인한 고유 후기만 남기고 배너의 정지·움직임 최소화 설정을 지원합니다.

**완료 기준:** 390/768/1440px 및 4개 언어에서 단어가 어색하게 잘리지 않음. 움직임 최소화 설정에서는 배너 정지. [검수한 랜딩 화면](assets/landing-desktop.png).

근거: [사용 흐름](../../src/features/landing/ui/LandingWorkflowSection.tsx), [후기 배너](https://github.com/gksktl111/easy-clip-fe/blob/2a8a16a/src/features/landing/ui/LandingReviewsBanner.tsx).

## D4 · P2 — 클립 카드의 본문 확인과 밀도 [제안]

클립 유형과 길이에 상관없이 카드 높이가 240px이고 텍스트는 4줄에서 잘립니다. 카드의 주 동작은 복사여서 긴 자료를 충분히 읽고 복사 대상을 확인하는 경로가 부족합니다. 짧은 메모도 큰 공간을 사용합니다.

**개선:** 복사 동작은 유지하면서 별도 미리보기/상세 열기를 제공합니다. 이미지 중심 그리드와 텍스트 중심 촘촘한 목록 중 제품 성격에 맞는 보조 보기를 검토합니다. 미리보기도 기존 폴더 잠금 정책을 따라야 합니다.

**완료 기준:** 긴 텍스트·긴 제목·태그 여러 개·이미지를 확인하고 정확한 항목을 복사할 수 있음. 밀도 변경 후 터치 영역과 키보드 포커스 유지.
