# 프로젝트 전체 검수

검수일: 2026-09-11 · 대상: 현재 로컬 `easy-clip-fe`와 인접 `easy-clip-be`

**핵심 기능은 상당 부분 구현됐지만, 개발 완료·운영 안전 판정은 아직 어렵습니다. 가격 계약과 인증·업로드 보안을 먼저 보완해야 합니다.** 이번 작업은 검수와 문서화이며 제품 코드는 변경하지 않았습니다.

## 실행 범위

[통합 이슈 #181](https://github.com/gksktl111/easy-clip-fe/issues/181), FE 브랜치 `refactor/181`에서 진행합니다. 사용자가 **FE만 수정**하도록 확정했습니다. 서버 가격 계약과 서버 보안·결제 항목은 미완료로 추적하며 BE 코드는 수정하지 않습니다. 아래 검증 표는 최초 검수 당시 결과이며 후속 구현 완료를 뜻하지 않습니다.

[정책 문서 초안](../legal/README.md)은 F3의 보조 산출물입니다. 운영 정책 확정과 실제 페이지 연결은 별도 완료 조건입니다.

## 개선 순서

P0는 즉시 조치, P1은 다음 배포 전 해결, P2는 후속 개선입니다. 일정 추정이 아닌 작업 순서입니다.

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 · P0 | Next.js 이미지 최적화 취약점 대응 | 영향 없는 패치 버전·배포 아티팩트 확인, 이미지 표시·복사 회귀 검증 |
| 2 · P1 | 표시 가격과 청구액 단일화 | 가격표·결제 화면·최초 결제·자동갱신이 같은 서버 가격 사용 |
| 3 · P1 | CSRF·OAuth 요청 연결·예외 로그·업로드 제한 보완 | 타 출처 요청·다른 브라우저 콜백·초과 파일 거부, 인증 쿼리가 로그에 남지 않음 |
| 4 · P1 | 로그아웃 실패와 최초 결제 중복 방지 보완 | 실패 시 성공 알림 없음, 동일 결제 시도 중복 청구 없음 |
| 5 · P1/P2 | 약관 링크·상품 설명·번역·모달 수정 | 안내한 기능과 실제 동작 일치, 네 언어와 키보드 흐름 확인 |
| 6 · P2 | Ponytail 기준 중복·강제 지연·불필요한 재조회와 렌더 정리, 디자인 개선 | 기존 기능 유지, 요청·렌더·응답 시간의 변경 전후 비교 |

## 확인한 범위와 검증 결과

개발 의도는 저장소의 구독·폴더 잠금·태그 연동 가이드, 현재 화면 문구, FE/BE 코드와 기존 테스트를 기준으로 판단했습니다. 별도 제품 명세에 없는 기능은 미구현 결함으로 단정하지 않았습니다. 작업 시작 시 두 저장소 모두 미커밋 변경이 없었습니다.

| 실제 실행 | 결과 |
| --- | --- |
| FE `npm run lint` | 통과 |
| FE `npm run typecheck` | 통과 — 현재 package.json에 스크립트 존재 |
| FE `npm run test` | 26개 파일, 120개 테스트 통과 |
| FE `npm run build` | 프로덕션 빌드 통과 |
| FE `npm run test:e2e -- --workers=2` | Chromium 93개 통과 |
| BE `npm test -- --runInBand --cacheDirectory=/tmp/easy-clip-review-jest` | 53개 스위트, 264개 테스트 통과 |
| 추가 로컬 브라우저 검수 | 로그아웃 실패·새로고침, 설정 Tab/Esc, 영어 결제 화면 문제 재현. 랜딩·작업 화면 시각 확인 |

Chrome DevTools는 `Target closed`로 연결되지 않아 Playwright로 대체했습니다. E2E 최초 실행의 localhost `EPERM`은 실행 권한을 조정한 뒤 해결했습니다.

**검증 한계:** 브라우저 테스트의 인증·구독·클립 API는 가짜 응답입니다. 실제 OAuth 로그인, Toss 결제, 운영 가격 환경변수, CDN/WAF 설정, 배포된 서버·DB 마이그레이션, DB 통합 테스트와 전체 의존성 취약점 스캔은 검증하지 않았습니다. 보안 공격이나 실제 과금도 수행하지 않았습니다. 테스트 통과는 이 범위의 회귀 확인이며 운영 전체의 안전성을 보증하지 않습니다.
