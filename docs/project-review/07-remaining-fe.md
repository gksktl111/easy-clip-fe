# 남은 작업 · FE

최초 목록: 2026-09-11. 후속 구현: 2026-09-13 · 사용자 요청에 따라 FE 작업을 진행했다.
BE 전달 목록은 [08 문서](08-remaining-be.md)를 참고한다.

## 2026-09-14 검색·태그 Pro 제한

BE 작업 완료를 전제로 FE 구현을 반영했다. Free는 폴더·최근·즐겨찾기의 검색 및 태그 관리·편집 진입을 숨기고 관련 조회·저장 요청을 제한한다. 기존 클립 태그는 읽기 전용으로 보존하며, 일반 클립·유형 필터·복사·즐겨찾기는 유지한다. 구독 권한 변경 시 검색어·모달·캐시를 정리한다. 요금표와 랜딩의 네 언어 안내도 수정했다.

BE 로컬 완료 보고를 받은 뒤 오류 안내를 검색·태그·재정렬별로 보완했다. 새 응답 필드는 추가하지 않으며 실제 통합·배포 확인은 남아 있다.

세부 구현과 검증은 [09 FE 문서](09-free-search-tags-fe.md), BE 차단·오류·운영 전환 확인은 [10 BE 문서](10-free-search-tags-be.md)를 참고한다.

## 2026-09-13 FE 적용 결과

- 가격표·결제 화면의 3,900원 표시 상수를 제거하고 `GET /subscriptions/pricing`의 금액·통화·월간 주기·가격 버전을 사용한다. 가격 조회 실패 또는 지원하지 않는 계약에서는 대체 금액 없이 안내·재조회와 결제 차단을 제공한다.
- 결제 인증 요청의 `price`와 표시한 가격이 다르면 SDK를 열지 않고 최신 가격을 다시 표시한다. 사용자가 다시 시작해야 결제 인증을 진행한다.
- 변경 요청에 `X-CSRF-Protection: 1`을 추가한다. JSON·multipart·토큰 갱신·인증 후 재시도에 공통 적용하고 GET 요청에는 추가하지 않는다. OAuth는 기존 브라우저 이동 경로를 유지한다.
- 카드 인증 전에 UUID 멱등키·가격 버전을 사용자별로 구분한 로컬 저장소에 기록한다. 인증 키는 저장하지 않는다. Web Locks로 탭 간 시도 생성을 조정하며, 리다이렉트의 `paymentAttempt`로 이전·새 결제 흐름을 구분한다. confirm에는 `idempotencyKey`·`priceVersion`을 함께 보낸다.
- 결제 응답의 `PENDING`·`DONE`·`FAILED`·`CANCELED`를 구분한다. 응답 유실·새로고침에는 동일 멱등키의 결과를 조회하며 승인 POST를 자동 재전송하지 않는다. `DONE`이면 항상 최신 구독을 다시 조회하고 권한 캐시를 갱신한다. `PENDING` 재확인 시 기존 주문의 reconcile을 호출해 복구하며 새 결제 시작을 차단한다. 결과 미확정 화면에서 다시 확인할 수 있다.
- 가격·업로드 안내는 한국어·영어·일본어·중국어에 반영했다. 업로드 413·429·503을 구분하고 `Retry-After` 동안 초안 재전송을 차단한다.
- 전체 검증에서 상단 알림이 모바일 검색 버튼을 덮고 hover로 닫힘이 멈추는 문제를 재현했다. 알림을 화면 하단에서 96px 띄운 중앙 위치로 이동해 하단 작업 버튼과 겹치지 않게 했다.

계약 근거는 사용자가 전달한 2026-09-13 BE #161 `feat/161` P1 계약과 로컬 BE 구현이다. 아직 배포되지 않은 계약이므로 FE·BE 전환 시점을 맞춰야 한다. 실제 인증·결제 통합 검증과 운영 배포는 별도 완료 조건이다. 운영 가격은 FE에서 결정하지 않았다.

### 검증

- 린트·타입 검사·프로덕션 빌드 통과. 샌드박스에서는 Next.js TypeScript 하위 프로세스 출력 파싱이 실패해 같은 빌드를 샌드박스 밖에서 검증했다.
- 단위 테스트 27개 파일, 138개 통과: 가격 유효성, CSRF 헤더와 인증 재시도, 결제 중복 방지·응답 유실 복구·사용자 분리 포함.
- 기본 붙여넣기 E2E 7개는 통과했다. 전체 실행에서는 `paste-responsive.spec.ts`에서 알림 겹침이 재현되어 위 위치 수정으로 대응했다.
- 공통 알림 변경의 Storybook 프로덕션 빌드 통과.
- 최종 전체 E2E **131개 통과(2.6분), 실패·재시도 없음**. 서버 가격 변경·조회 실패 차단, 카드 인증부터 승인/새로고침 복구, 업로드 Retry-After, 4개 언어의 모바일 검색·알림과 휴지통 회귀를 포함한다.
- Chrome DevTools MCP는 브라우저 연결 오류(`Target closed`)로 사용할 수 없었다. 실행 흐름 검증은 Playwright로 수행한다.

## 완료한 작업 · 다시 구현하지 않음

모바일 폴더 헤더, 데스크톱/모바일 붙여넣기 분리, 권한 확인 스켈레톤, 휴지통 상세 보기·하단 선택 작업은 구현·커밋 완료했다.
휴지통 BE는 별도 에이전트가 구현했고 실행 컨테이너 불일치 진단 후 사용자가 화면 동작을 확인했다.
이는 운영 전체 배포 및 에이전트의 인증된 실제 응답 직접 검증까지 완료했다는 뜻은 아니다.
