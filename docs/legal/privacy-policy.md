## 2. 외부 업체와 제공·위탁

아래는 연동 코드가 있는 업체이며, 모두 운영 중이라고 확정한 목록은 아닙니다. 수탁·제3자 제공·독립 서비스 관계를 계약과 실제 데이터 흐름에 따라 구분한 뒤 공개합니다.

| 업체·서비스 후보 | 코드상 역할 | 공개 전 확인 |
| --- | --- | --- |
| Google / GitHub | 소셜 로그인과 프로필 정보 전달 | 실제 활성 제공자, 요청 범위, 전달 방향과 법적 관계 |
| Toss Payments | 결제수단 등록·정기 결제 | 계약 법인, 전달 항목·목적·보유 기간, 위탁 또는 제공 구분 |
| Cloudflare R2 | 업로드 이미지 저장·전달 | 계약 법인, 저장 위치, CDN·삭제·백업 조건 |
| Resend | 구독·결제 안내 이메일 | 발송 활성화 여부, 계약 법인, 수신자·본문 보관 조건 |
| [확정 필요: 호스팅·DB·로그·지원 업체] | 인프라 운영 등 | 실제 업체와 위탁 업무·처리 항목 |

## 6. 쿠키와 브라우저 저장

로그인 상태 유지와 언어·테마 설정을 위해 쿠키를 사용합니다. 이용자는 브라우저 설정에서 쿠키를 삭제·차단할 수 있으며, 이 경우 로그인 유지 또는 설정 저장이 제한될 수 있습니다. 작성 중인 클립 등 일부 화면 상태는 브라우저 메모리에 임시로 유지됩니다.

| 쿠키 | 목적 | 코드상 만료 |
| --- | --- | --- |
| `easy_clip_access_token` | 인증된 API 요청 | 발급 시 30분 |
| `easy_clip_refresh_token` | 로그인 갱신 | 발급 시 14일 |
| `easy_clip_theme` | 화면 테마 유지 | 설정 기록 시 365일 |
| `easy_clip_language` | 표시 언어 유지 | 설정 기록 시 365일 |

인증 쿠키 이름은 운영 설정으로 바뀔 수 있습니다. 갱신·설정 변경 시 만료가 다시 설정될 수 있으며, 쿠키 만료가 서버의 토큰 기록·이용기록 삭제를 의미하지 않습니다. 서버 기록의 보유 기간은 1·4항에서 별도로 확정합니다.

로그아웃 종료 요청 여부를 `sessionStorage`의 `easy_clip_logout_requested`에 기록합니다. 실패 후 같은 탭에서 자료가 다시 열리지 않도록 하는 참/거짓 상태이며 콘텐츠나 인증 토큰을 담지 않습니다. 종료 요청 성공 시 제거하고, 그 외에는 해당 탭의 브라우저 세션 수명에 따릅니다.
