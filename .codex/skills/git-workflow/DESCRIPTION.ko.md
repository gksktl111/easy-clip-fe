# Git/GitHub 워크플로

Easy Clip 저장소의 이슈, 브랜치, 커밋, push, PR, 병합과 이력 관리 절차를 제공하는 저장소 로컬 Codex 스킬입니다. GitHub 관련 전용 에이전트 작업은 `gpt-5.4`로 고정합니다.

다음 작업에서 사용합니다.

- GitHub 이슈 생성과 분류
- 브랜치 생성, 동기화와 정리
- 커밋과 push
- PR 생성, 수정, 리뷰와 병합
- `dev`에서 `main`으로 승격
- force push와 history rewrite 같은 위험 작업

## 에이전트 모델 선택

사용자가 선택한 최상위 에이전트 모델은 유지합니다. 새 GitHub 작업 또는 별도 에이전트 위임 시에는 작업 난이도와 무관하게 `gpt-5.4`를 사용합니다.

- `gpt-5.6` 계열이나 다른 모델로 자동 승격·대체하지 않습니다.
- `gpt-5.4`를 사용할 수 없으면 다른 모델로 조용히 바꾸지 않고 사용자에게 알립니다.
- 기존 검증과 위험 작업의 사용자 승인 절차는 그대로 적용합니다.
